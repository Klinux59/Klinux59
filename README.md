### 02 / WEB DEVELOPMENT / BKK DETAILING

**BKK Detailing — ระบบจัดการร้านดูแลรถยนต์และสมาชิก**  
พัฒนาและออกแบบโดย **K59 Studio** · อัปเดต **2026**

<p align="center">
  <img src="./assets/projects/bkk-detailing.svg" width="100%" alt="ภาพประกอบผลงาน BKK Detailing โดย K59 Studio — ระบบสมาชิก โปรไฟล์รถ E-Warranty POS และรายรับรายจ่าย" />
</p>

ระบบเว็บสำหรับงานหน้าร้านและการดูแลลูกค้าหลังรับบริการ รวมข้อมูลสมาชิก รถ ประวัติบริการ และการรับประกันไว้ในระบบเดียว พร้อมหน้าลูกค้าสำหรับดูข้อมูลของตนเอง

| รายการ | ข้อมูลผลงาน |
| :--- | :--- |
| **ส่วนที่พัฒนา** | ออกแบบ UI และขั้นตอนใช้งาน พัฒนาหน้าลูกค้าและหลังบ้าน เชื่อมการทำงานกับฐานข้อมูล และติดตั้งบนเซิร์ฟเวอร์ |
| **สมาชิกและโปรไฟล์รถ** | สมัครและแก้ไขข้อมูลสมาชิก จัดการรถหลายคัน อัปโหลดรูปโปรไฟล์รถ และดูประวัติบริการ |
| **บริการและการดูแลต่อเนื่อง** | POS จองคิว ใบเสนอราคา แพ็กเกจสมาชิก และ E-Warranty |
| **การเงินและสิทธิ์ผู้ใช้** | บันทึกรายรับรายจ่าย แยกสิทธิ์เจ้าของ พนักงาน และช่าง พร้อมบันทึกกิจกรรม |
| **เทคโนโลยี** | PHP · Laravel 12 · MySQL · Blade · Alpine.js · Tailwind CSS · Vite |
| **เซิร์ฟเวอร์** | Windows Server · XAMPP / Apache · HTTPS |
| **แนวทาง UI** | ดำคาร์บอน ขาวนวล และแดง พร้อมฟอนต์ Kanit รองรับมือถือ |
| **สถานะ** | นำขึ้นเซิร์ฟเวอร์แล้ว อยู่ระหว่างทดสอบและปรับปรุงระบบจริง |
| **เครดิต / ปีอัปเดต** | K59 Studio · 2026 |

### 03 / GAME SERVERS / TOOLS

**FiveM Control Center — ศูนย์ควบคุมเซิร์ฟเวอร์และข้อมูลผู้เล่น**  
พัฒนาและออกแบบโดย **K59 Studio** · อัปเดต **2026**

<p align="center">
  <img src="./assets/projects/fivem-control-center.jpg" width="100%" alt="FiveM Control Center โดย K59 Studio — แดชบอร์ดโทนดำ ครีม และแดง พร้อมสถานะเซิร์ฟเวอร์ ฐานข้อมูล และเมนูจัดการผู้เล่น" />
</p>

เว็บแดชบอร์ดสำหรับดูแลเซิร์ฟเวอร์ FiveM / ESX รวมการควบคุมเกม ฐานข้อมูล ผู้เล่น และบันทึกระบบไว้ในพื้นที่เดียว จัดเมนูตามงานที่ใช้ประจำ พร้อมช่องค้นหาและทางลัดเพื่อลดขั้นตอนการใช้งาน

| รายการ | ข้อมูลผลงาน |
| :--- | :--- |
| **ส่วนที่พัฒนาและปรับปรุง** | ออกแบบ UI และลำดับการใช้งาน จัดหมวดเมนู เชื่อมหน้าควบคุมกับ API เดิม และปรับธีม Player Database ให้สอดคล้องกัน |
| **ควบคุมเซิร์ฟเวอร์** | เปิด ปิด และรีสตาร์ทเกม / FXServer / MariaDB พร้อมการนับถอยหลังและประกาศในเกม |
| **สถานะและประสิทธิภาพ** | แสดงจำนวนผู้เล่น CPU, RAM, เครือข่าย และพื้นที่ดิสก์ พร้อมสถานะการเชื่อมต่อสด |
| **ผู้เล่นและข้อมูล** | รายชื่อผู้เล่นออนไลน์และหน้า Player Database สำหรับดูแลข้อมูลผู้เล่น |
| **ตรวจสอบระบบ** | Live Console, Log Hub, บันทึก Anti-cheat, ประวัติเข้าระบบ และหน้าตรวจความปลอดภัย |
| **การใช้งานที่ชัดเจนขึ้น** | ค้นหาเมนู ทางลัดงานหลัก พับคำสั่งขั้นสูง ยืนยันก่อนปิด / รีสตาร์ท และล็อกปุ่มระหว่างรอคำสั่งเพื่อป้องกันการกดซ้อน |
| **เทคโนโลยี** | Node.js · Express · JavaScript · HTML / CSS · MariaDB / MySQL · Server-Sent Events · Three.js |
| **แนวทาง UI** | ดำคาร์บอน ครีม และแดง แยกสถานะออกจากปุ่มคำสั่ง พร้อมเมนูสำหรับหน้าจอขนาดเล็ก |
| **สถานะ** | อัปเดต UI และติดตั้งในชุดโปรเจกต์แล้ว ตรวจหน้าเว็บด้วยข้อมูลจำลอง ยังไม่ได้ทดสอบคำสั่งควบคุมเซิร์ฟเวอร์จริงหลังอัปเดต |
| **เครดิต / ปีอัปเดต** | K59 Studio · 2026 |

<sub>ภาพด้านบนเป็นหน้าเว็บที่ทดสอบด้วยข้อมูลจำลอง ไม่ใช่ข้อมูลผู้เล่นหรือสถานะเซิร์ฟเวอร์จริง</sub>
